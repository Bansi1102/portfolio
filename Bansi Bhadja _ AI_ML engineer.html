Selected work

Built at Panva Technology Solutions for a revenue cycle management platform.

Payer-policy document RAG

SentenceTransformers, FAISS, Llama 3.1 8B (Ollama)

PDF ingestion with 512-token chunks and 64-token overlap, answered locally or through Azure OpenAI, with a normalized question cache.

CPT/ICD extraction and fine-tuned Llama

LoRA, ~50k JSONL examples, FAISS, Azure OpenAI

Replaced TF-IDF retrieval with per-tenant RAG and a similarity-threshold cache. Two LoRA models: one extracts codes from SOAP notes, one validates billed codes against NCCI. Tenant rules override model output.

~97% validation accuracy on NCCI validation.

Natural-language analytics

Vanna AI, Azure OpenAI, FAISS, DuckDB, SQLGlot

An 8-stage Text-to-SQL pipeline: intent and entity resolution, vector-grounded SQL, AST validation (read-only, table allowlist, 5,000-row cap), then DuckDB execution and streaming answers. Each tenant has its own database and vector index.

Generated SQL is validated before it touches data.

Claims intelligence platform

FastAPI, XGBoost, FAISS, Azure OpenAI, SHAP

Clinical coding RAG, payer behavior models, NCCI checks and AI claim review in one platform. Time-based validation avoids leakage, SHAP explains denial risk, and FP-Growth mining across 9 pipelines finds denial and underpayment patterns.

Pattern analytics API cut from about 276 s to 4.2 s.

Prediction models and MLOps

XGBoost, scikit-learn, Evidently, Prometheus

Tenant-isolated models for payment percentage, payment timing, provider cash flow and patient aging risk, retrained daily with checkpoint resume, drift alerts, logged R² and MAE, and one-step rollback.

R² of about 0.96 to 0.98 depending on the dataset.

Claim validation rules engine

FastAPI, SQLAlchemy, Pandas, Docker

A strategy-pattern engine with 16+ rule types (NCCI PTP, MUE, add-on codes, modifiers, LCD/NCD, place of service), strict PASS/FAIL results and audit trails.

Under 25 ms per 100-line batch.

EOB to EDI 835 pipeline

PaddleOCR, Azure Document Intelligence, Qwen2.5-VL

Scanned remittances become X12 835 files through OCR, payer-specific parsers and balance checks, with a human-review queue for low-confidence results.

Secure production deployment

Gunicorn, systemd, NGINX, JWT, Docker, Presidio, spaCy

APIs run on Azure Linux VMs and in containers. Legacy Flask endpoints moved to FastAPI behind a compatibility proxy. Patient data is redacted before any text reaches an LLM.

Zero patient identifiers in model inputs or artifacts.
